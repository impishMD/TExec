# TExec v1.0.0

TExec — платформа автоматизации для самостоятельного размещения, независимый форк Semaphore UI.

- Запуск Ansible, Terraform, OpenTofu, Terragrunt и скриптов через веб-интерфейс и API.
- Проекты, репозитории, инвентари, ключи, шаблоны задач, рабочие процессы и расписания.
- Роли, персональные и проектные API-токены, OIDC, LDAP и двухфакторная аутентификация.
- Журналы выполнения, аудит событий и оповещения проектов.
- Развёртывание через бинарные файлы Linux/macOS, DEB/RPM, Docker Compose или Helm.

Образы для `linux/amd64` и `linux/arm64` публикуются в `impishmd/texec` и `ghcr.io/impishmd/texec`: `v1.0.0`, `v1.0.0-runner`, `v1.0.0-job` и `v1.0.0-helper`.

Helm-чарт `texec` версии `1.0.0` публикуется отдельно с тегом `chart-v1.0.0`: https://impishmd.github.io/TExec.
