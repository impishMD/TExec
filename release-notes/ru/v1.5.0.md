# TExec v1.5.0

## Топики Telegram

- Добавлено необязательное поле **ID топика** в **Настройки проекта → Оповещения → Telegram → Основные**. Теперь уведомления можно направлять в отдельный топик группы.
- Уведомления об успехе и ошибке задач, сообщения рабочих процессов и запросы подтверждения используют топик проекта.
- Общая кнопка тестирования использует текущие значения формы, включая несохранённый ID топика. В глобальных настройках бота также можно указать временный ID топика для проверки токена.
- ID топика проходит проверку; поле недоступно при выключенном канале. Очистка и сохранение поля возвращает отправку без указания топика. При ошибке доставки сообщение не перенаправляется в общий топик.

## Обновление

Миграция схемы базы данных и новые параметры развёртывания не требуются. Существующие проекты продолжают работать как раньше, пока ID топика не задан. Укажите числовой Telegram `message_thread_id`, а не название топика; у бота должны быть права отправлять туда сообщения.

Образы публикуются в Docker Hub и GHCR для `linux/amd64` и `linux/arm64`. Helm-чарт **1.5.0** выпускается отдельно.
