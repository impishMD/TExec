# TExec v1.4.1

## Исправления

- Исправлены пустые графики статусов задач в панели управления и подробностях шаблонов, когда PostgreSQL/MySQL возвращает дату вместе со временем. Счётчики теперь учитывают календарный день из API без сдвига часового пояса.
- Исправлены подписи в подробностях шаблонов: Ansible — **Плейбук**, Bash/Python/PowerShell — **Скрипт**, Terraform/OpenTofu/Terragrunt/Pulumi — **Каталог**.
- Для Terraform-семейства отображается **Рабочее пространство** вместо **Инвентарь**. У скриптов и Pulumi убрана неиспользуемая карточка инвентаря.
- Уточнены заголовки столбцов общего списка шаблонов; сообщение об обязательном пути к скрипту больше не называет его плейбуком.

## Обновление

Миграция схемы базы данных и новые параметры развёртывания не требуются. Существующие настройки совместимы.

Образы публикуются в Docker Hub и GHCR для `linux/amd64` и `linux/arm64`. Helm-чарт **1.4.1** выпускается отдельно.
