# TExec v1.3.0

- В общие настройки добавлен часовой пояс расписаний с сохранением в базе данных.
- Переменная окружения и конфигурационный файл имеют приоритет над сохранённой настройкой. При их использовании поле заблокировано с объяснением причины.
- Исправлено расположение переключателя включения расписания и добавлен заголовок столбца состояния.
- Исправлена суточная статистика: учитываются ошибки и остановленные задачи без времени начала, столбцы статусов корректно складываются.
- Улучшена читаемость графика в тёмной теме; из подсказок по дням убрано лишнее время.
- Для Terraform, OpenTofu и Terragrunt подпись параметра запуска исправлена на «Рабочее пространство».
- Для PR в dev добавлены быстрые проверки; полная проверка выполняется на релизных ветках.

При обновлении: если часовой пояс явно не задан, расписания теперь используют системную таймзону сервера вместо UTC. В Docker это таймзона контейнера. Чтобы сохранить выполнение по UTC, явно укажите UTC.

Приоритет: TEXEC_SCHEDULE_TIMEZONE > schedule.timezone в конфигурационном файле > настройка в базе > системная таймзона.

Образы публикуются в Docker Hub и GHCR для linux/amd64 и linux/arm64. Helm-чарт 1.3.0 выпускается отдельно.
