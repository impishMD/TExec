# TExec v1.5.0

## Telegram topics

- Added an optional **Topic ID** under **Project settings → Notifications → Telegram → General**. Notifications can now be sent to a selected forum topic within a group.
- Task success/error messages, workflow notifications and approval alerts use the project's topic.
- The existing test button uses the current form values, including an unsaved Topic ID. Global bot settings also accept a temporary Topic ID for credential tests.
- The Topic ID is validated and its field is disabled while the channel is off. Clearing and saving the field restores delivery without an explicit topic. Failed delivery to a topic does not redirect the message to the General topic.

## Upgrading

No database schema migration or new deployment settings are required. Existing projects keep their previous behavior until a Topic ID is configured. Enter the numeric Telegram `message_thread_id`, not the topic name; the bot needs permission to send messages to that topic.

Container images are published to Docker Hub and GHCR for `linux/amd64` and `linux/arm64`. Helm chart **1.5.0** is published separately.
