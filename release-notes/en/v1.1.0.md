# TExec v1.1.0

## Workflows

- Send Telegram messages from notification nodes or when a workflow needs approval, using the project's notification settings.
- Customize messages with the project and workflow names, run number and link, date/time, predecessor status/error and approval deadline. Preview messages and send a test from the editor.
- Keep the notification queue and delivery history across restarts, retry failed deliveries and choose whether a notification failure should fail its step.
- Read full workflow statuses, names, revision numbers and counters in improved editor and run headers.

## Ansible inventories

- Select a repository to browse inventory file suggestions: `.ini`, `.yml`, `.yaml` and extensionless files such as `hosts`.
- Enter a path manually, refresh suggestions or use an inventory without a separate repository.

## Deployment

Back up the database before upgrading; startup applies the notification queue migration. Update server and runners together.

Images for `linux/amd64` and `linux/arm64` are published to `impishmd/texec` and `ghcr.io/impishmd/texec`: `v1.1.0`, `v1.1.0-runner`, `v1.1.0-job` and `v1.1.0-helper`.

Helm chart `texec` 1.1.0 is published separately under `chart-v1.1.0` at https://impishmd.github.io/TExec.

Release branches now run CI, package checks and applicable Helm checks. Tagged releases reuse successful CI for the exact commit without repeating the full race test suite.
