# TExec v1.4.1

## Fixes

- Fixed empty task status charts in the project dashboard and template details when PostgreSQL/MySQL returns dates with a time component. Counts now match the API's calendar day without timezone shifts.
- Corrected template details: Ansible uses **Playbook**, Bash/Python/PowerShell use **Script**, and Terraform/OpenTofu/Terragrunt/Pulumi use **Directory**.
- Terraform-family templates show **Workspace** instead of **Inventory**. Script and Pulumi templates no longer show an unused inventory card.
- Updated the mixed template list's column labels and removed the misleading playbook-specific validation message from script forms.

## Upgrading

No database schema migration or new deployment settings are required. Existing configuration remains compatible.

Container images are published to Docker Hub and GHCR for `linux/amd64` and `linux/arm64`. Helm chart **1.4.1** is published separately.
