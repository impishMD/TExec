# TExec v1.0.0

TExec is a self-hosted automation platform and an independent fork of Semaphore UI.

- Run Ansible, Terraform, OpenTofu, Terragrunt and scripts through the web interface or API.
- Organize projects, repositories, inventories, credentials, templates, workflows and schedules.
- Control access with roles, personal and project API tokens, OIDC, LDAP and two-factor authentication.
- Inspect execution logs and audit events, and configure project notifications.
- Deploy with Linux/macOS binaries, DEB/RPM packages, Docker Compose or Helm.

Docker images are published for `linux/amd64` and `linux/arm64` to `impishmd/texec` and `ghcr.io/impishmd/texec`: `v1.0.0`, `v1.0.0-runner`, `v1.0.0-job` and `v1.0.0-helper`.

Helm chart `texec` version `1.0.0` is published separately under `chart-v1.0.0` at https://impishmd.github.io/TExec.
