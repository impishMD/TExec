# TExec v1.2.0

## Project notification templates

- Customize task success and error messages in **Project settings → Notifications → Telegram → Message templates**. Each channel owns its templates.
- Insert project and template names, task number, status, author, link, message, version, error summary and completion date/time. Preview the result and select a time zone.
- Reset the selected template to defaults in the current interface language, with support for all 15 interface languages. Saved text and its status language remain unchanged when another user views it or changes their interface language.
- Use **General** and **Message templates** tabs within Telegram. A single save action stores channel settings and templates; a single test action sends the selected example using the current form values.
- Template controls and testing remain disabled until the channel is enabled. Task-level success/error notification switches continue to take priority.
- Include per-channel templates in project backups and imports, without copying bot tokens, destinations or enabled states.

Messages use plain text and named variables. Error summaries are shortened and common credential patterns are redacted.

## Deployment

Back up the database before upgrading. Startup applies the notification template migrations. Existing channel settings and credentials are preserved; channels without customized templates keep their existing message format. Update server and runners together.

Images for `linux/amd64` and `linux/arm64` are published to `impishmd/texec` and `ghcr.io/impishmd/texec`: `v1.2.0`, `v1.2.0-runner`, `v1.2.0-job` and `v1.2.0-helper`.

Helm chart `texec` 1.2.0 is published separately under `chart-v1.2.0` at https://impishmd.github.io/TExec. Existing chart values remain compatible.
