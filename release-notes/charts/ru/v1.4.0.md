# Helm-чарт TExec v1.4.0

- Образ приложения по умолчанию обновлён до TExec v1.4.0: общие и персональные темы оформления, цвета логотипа и favicon по выбранной теме.
- Настройки оформления задаются в приложении и хранятся в его базе данных; дополнительные параметры Helm не нужны.
- Существующие настройки чарта совместимы.

Helm-репозиторий: https://impishmd.github.io/TExec
