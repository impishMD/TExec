# Helm-чарт TExec v1.0.0

- Развёртывание TExec v1.0.0 с постоянным хранилищем, ingress, внешней базой данных и OIDC.
- Поддержка существующих Kubernetes Secrets для учётных данных и ключей шифрования.
- Имя чарта: `texec`. Репозиторий: https://impishmd.github.io/TExec.
- Основан на Semaphore UI Charts; лицензия Apache-2.0 и атрибуция включены в пакет.
