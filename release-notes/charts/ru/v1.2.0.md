# Helm-чарт TExec v1.2.0

- Образ приложения по умолчанию обновлён до TExec v1.2.0: шаблоны оповещений проекта для отдельных каналов, стандартные тексты на языке интерфейса и единая форма настроек Telegram.
- Существующие значения настроек чарта и конфигурация развёртывания совместимы.
- Имя чарта: `texec`. Репозиторий: https://impishmd.github.io/TExec.

Перед обновлением сделайте резервную копию базы данных приложения. TExec применяет миграции шаблонов оповещений при запуске.
