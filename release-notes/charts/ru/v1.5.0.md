# Helm-чарт TExec v1.5.0

- Образ приложения по умолчанию обновлён до TExec v1.5.0 с поддержкой топиков Telegram для результатов задач, уведомлений рабочих процессов и запросов подтверждения.
- Существующие настройки чарта совместимы; дополнительные параметры Helm и миграция схемы базы данных не нужны. Необязательный ID топика задаётся в настройках Telegram проекта.

Helm-репозиторий: https://impishmd.github.io/TExec
