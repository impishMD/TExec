# Helm-чарт TExec v1.1.0

- Образ приложения по умолчанию обновлён до TExec v1.1.0: оповещения рабочих процессов, уведомления о запросах подтверждения и подсказки файлов инвентаря Ansible.
- Сохранена совместимость существующих values и настроек развёртывания.
- Название чарта: `texec`. Репозиторий: https://impishmd.github.io/TExec.

Перед обновлением сохраните резервную копию базы данных приложения. TExec применяет миграцию очереди оповещений при старте.
