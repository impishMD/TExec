# TExec Helm chart v1.2.0

- Updates the default application image to TExec v1.2.0 with per-channel project notification templates, localized defaults and a unified Telegram settings form.
- Keeps existing chart values and deployment configuration compatible.
- Chart name: `texec`. Repository: https://impishmd.github.io/TExec.

Back up the application database before upgrading. TExec applies its notification template migrations on startup.
