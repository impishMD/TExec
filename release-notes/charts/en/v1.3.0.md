# TExec Helm chart v1.3.0

- Updated the default application image to TExec v1.3.0.
- Existing chart values remain compatible.
- Without an explicit schedule timezone, the application now uses the container's system timezone. Configure UTC explicitly to preserve UTC scheduling.
