# TExec Helm chart v1.0.0

- Deploys TExec v1.0.0 with persistent storage, ingress, external database support and OIDC configuration.
- Supports existing Kubernetes Secrets for credentials and encryption keys.
- Chart name: `texec`. Repository: https://impishmd.github.io/TExec.
- Based on Semaphore UI Charts; Apache-2.0 license and upstream attribution are included.
