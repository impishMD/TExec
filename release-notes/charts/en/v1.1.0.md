# TExec Helm chart v1.1.0

- Updates the default application image to TExec v1.1.0 with workflow notifications, approval alerts and Ansible inventory file suggestions.
- Keeps the existing chart values and deployment configuration compatible.
- Chart name: `texec`. Repository: https://impishmd.github.io/TExec.

Back up the application database before upgrading. TExec applies its notification queue migration on startup.
