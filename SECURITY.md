# Security policy

The latest TExec release in the 0.0.x series is supported. Versions of the upstream
project are not TExec release versions.

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/impishMD/TExec/security/advisories/new)
when enabled. Include the TExec version, reproduction steps and impact, without live credentials.
If private reporting is unavailable, contact the repository owner through their GitHub profile
before sending sensitive details. Do not publish working credentials in public issues.

The scope covers TExec source and artifacts published by this repository.
