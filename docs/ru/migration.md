# Миграция на TExec

[English](../en/migration.md) | **Русский**


## Переход с Semaphore UI

| Было | Стало |
| --- | --- |
| Бинарник, служба, пользователь `semaphore` | `texec` |
| Переменные `SEMAPHORE_*` | `TEXEC_*` |
| Ansible `semaphore_vars` | `texec_vars` |
| `/etc/semaphore`, `/var/lib/semaphore`, `/tmp/semaphore`, `/opt/semaphore` | Соответствующие пути `/…/texec` |
| Метрики `semaphore_*` | `texec_*` |
| Образы upstream | `impishmd/texec` или `ghcr.io/impishmd/texec` |
| Go-модуль `github.com/semaphoreui/semaphore` | `github.com/impishMD/TExec` |

Старый префикс окружения не является алиасом.
Существующие имена БД и абсолютные пути не меняются автоматически; новое имя БД по умолчанию — `texec`.

1. Остановите старую службу; сохраните БД, конфигурацию и ключи шифрования.
2. Проверьте восстановленную копию на TExec, особенно при переходе с другого upstream-коммита.
3. Обновите окружение, команды службы, пути и монтирования. Для существующей установки
   сохраните диалект/имя БД, ключ шифрования и ключи cookie.
4. Обновите раннеры одновременно с сервером; не смешивайте старые и новые раннеры.
5. Переведите dashboards/alerts на `texec_*`; при необходимости обновите клиентов.
6. Проверьте вход, доступ к репозиторию и запуск типовой задачи.

TExec применяет миграции базы при запуске. Для отката восстановите резервную копию БД
вместе с соответствующей версией приложения. Проверьте вход клиентов и окружение задач.
